# Kanban Board

A single-board Kanban MVP built with Next.js.

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tests

```bash
npm run test       # unit tests
npm run test:e2e   # Playwright E2E tests
```

## Build

```bash
npm run build
npm start
```
